# 地理智能平台 本机 Agent CLI

本机 Agent CLI 是桌面工作台的终端入口。它复用主服务中唯一的智能体运行、工具审批、工作流、审计和 PostgreSQL 会话事实源；CLI 只采集操作和呈现服务端事实，不创建第二套运行时，也不直接调用模型。

## macOS 正式包

正式桌面安装包已经携带命令行和本机后台，不需要源码目录、系统 Node.js 或 Docker。先将应用放入“应用程序”并启动，然后进入“设置 → 服务与模型 → 终端命令”，点击“安装命令”并完成一次 macOS 系统授权。应用只会创建以下固定链接：

```text
/usr/local/bin/geo-agent-platform
```

已有同名文件或其它应用的链接时不会覆盖；移动应用后，设置页会显示“修复命令”。安装完成后可在任意目录运行：

```bash
# 自动准备本机后台并进入交互式智能体
geo-agent-platform

# 执行一次任务并在结束后退出
geo-agent-platform -p "分析杭州今天的降雨风险"

# 打开本机运维台，而不是智能体对话
geo-agent-platform console
```

其它安装版入口包括 `geo-agent-platform start`、`status`、`logs`、`desktop`、`--help` 和 `--version`。直接传 `-p`、`--prompt`、`--mode`、`--provider`、`--model`、`--thread` 等参数时，默认交给智能体入口。

## 源码开发态

在仓库根目录直接运行 `./dev.sh`，会启动本机监督器和全部服务，然后打开的是**运维台**；它不等同于智能体对话。`./dev.sh console` 是同一入口的显式写法。

```bash
./dev.sh
./dev.sh console
./dev.sh agent
./dev.sh agent --prompt "杭州明天会下雨吗？"
./dev.sh agent --mode plan --prompt "比较杭州今天与明天的天气"
./dev.sh agent --check --json
```

Windows 开发态使用对应入口：

```powershell
.\dev.ps1
.\dev.ps1 console
.\dev.ps1 agent
.\dev.ps1 agent --prompt "杭州明天会下雨吗？"
.\dev.ps1 agent --check
```

开发入口会按需构建共享契约、启动监督器和 API，再连接本机控制通道。`--check` 只验证本机授权、数据库、API、工作区和模型能力，不创建运行。

一次性模式退出码：

- `0`：运行已完成；
- `1`：连接、协议、模型、运行或其他真实失败；
- `2`：运行正在等待澄清或审批，JSON 输出包含待处理决定。

## 交互界面

界面使用低饱和、高信息密度的中文布局：

- 中性深灰负责画布和层级，低饱和青灰只标识焦点、链接和主要操作；成功、等待和失败使用克制的语义色，不再为模型、思考和工具分别使用蓝色、紫色等装饰色。状态始终同时显示符号与中文标签。
- 真彩、256 色和 16 色终端分别使用对应调色板；16 色模式交还背景所有权。`NO_COLOR` 或 `TERM=dumb` 强制无色，文字、边框、选中符号和错误原因仍然完整。
- 顶部显示服务端实际模型提供商、模型、执行模式和连接状态。运行、思考、调用工具或子智能体协作时，只显示一个与真实阶段对应的活动指示器。
- 中央时间线增量更新：未变化的旧条目保留投影和排版缓存，流式回答只重排变化条目。默认从当前位置直接跟随最新内容，不会每次从顶部到末尾重新播放。
- 用户主动用滚轮或 `PgUp` 上翻后，视窗锚定当前首行；新内容继续到达时不会把正在阅读的位置推走，并显示未读行数。`PgDn` 到底、输入为空时按 `End`，或任何时候按 `Ctrl+End`，都会立即恢复跟随最新。
- 正常窗口中的输入区随内容占 3–6 个终端行，其中正文可见 1–4 行；紧凑布局固定为 3 行。支持中文和组合表情、粘贴、左右与上下移动、`Home`/`End`、退格、删除和 `Ctrl+J` 换行。
- 输入区内的 `↑`/`↓` 先按视觉行移动；到达首尾后继续按可依次召回本次终端提交的历史，并在返回末端时恢复尚未发送的草稿。
- `/history` 打开服务端最近对话；直接输入文字会按标题、最近问题、最近回答和预览筛选，`↑`/`↓` 选择，`Enter` 打开。
- 已成功的工具调用默认折叠，失败或等待批准的工具保留详情。输入为空时用 `Tab`/`Shift+Tab` 选择工具记录，再按 `Enter` 展开或收起；也可以单击工具标题。
- 助手正文和思考使用终端 Markdown 渲染标题、强调、链接、列表、引用、表格、任务列表和代码框，并按当前宽度重新排版。
- 达到 `140×32` 时右侧显示运行检查器；`60×16` 仍提供完整紧凑交互，低于 `60×16` 才暂停业务区并显示尺寸提示。
- 鼠标只处理点击和滚轮，不启用移动追踪，终端原生文本选择仍可使用。

需要稳定截图、无动画录制或对动态效果敏感时，可设置
`GEO_AGENT_PLATFORM_REDUCED_MOTION=1`。`CI=true` 与 `TERM=dumb` 也会自动使用带中文标签的静态状态符号；`NO_COLOR` 终端仍保留全部文字和状态语义。

普通字母不会被当作全局快捷键。`q`、`S`、`R` 和 `?` 都可正常输入；只有输入区为空时，`?` 会打开帮助。输入 `/` 会显示来自统一命令注册表的补全菜单，可用方向键选择并用 `Tab` 或 `Enter` 补全。

常用命令：

```text
/help  /new  /history  /status  /model
/plan  /auto  /reasoning on|off
/resume  /cancel  /tools  /agents  /exit
```

`Ctrl+C` 在运行中取消 run，有文本时清空输入，空闲时连续按两次才分离。分离不会停止 API、Worker、Electron 桌面端或监督器。

审批默认选中“拒绝”。选择批准后必须再次确认，连接中断时写操作不会自动重放。

## 本机授权与模型凭据边界

CLI 不要求输入现有管理员账号密码，也没有硬编码万能账号。

1. 服务端本机 Broker 使用操作系统访问控制保护的本地主体材料，建立仅存于当前进程内存的短期会话；公共登录和远程连接不能借用这条通道。
2. CLI 不读取 macOS 系统钥匙串、Windows 凭据管理器或桌面端安全存储，也不会读取宿主环境中的 OpenAI、DeepSeek 等模型密钥。
3. 正式包启动器从空环境开始，只传终端显示和本机运行所需的固定非敏感字段；源码开发启动器和 Broker 同样会在读取值之前排除模型、签名和包管理凭据名称。
4. 模型服务地址和密钥在桌面“设置 → 服务与模型”中配置，只由服务端从数据库读取使用。CLI 只接收不含密钥的提供商描述、模型清单和运行结果。
5. 退出时立即关闭短期会话，并记录本机用户名、主机、进程、运行、对话和结果；会话 Cookie、本地主体材料与模型密钥不进入日志或审计。

这套授权只允许调用已经注册、带边界校验和权限规则的平台控制命令。它不是任意系统命令入口，不接入监督器任意命令，也不注册为智能体工具或自动化动作。

## 模型与协议

模型列表来自服务端提供商描述。默认不覆盖服务端选择；只有显式 `--model` 且模型位于该提供商的可用清单中时才发送。宿主 CLI 的模型名不会被继承，因此其它工具使用的模型不会被误传给当前服务；无效模型在创建运行前用中文明确失败。

控制连接使用带短期会话 Cookie、可信来源和防跨站请求校验的逐行 JSON WebSocket：

- 客户端请求最大 64 KiB；
- 响应缓冲最大 8 MiB；
- 响应和推送均经过共享信封与业务结构校验；
- 断线只重新订阅服务端权威运行，不重放未确认写入；
- JSON 输出只包含稳定的回答、决定、产物和错误摘要，不输出原始工具参数或工具结果。

## 代码组织

```text
apps/operations-console/src/
  installedCli.ts       # 正式安装包的统一命令路由与后台准备
  localConsole*.ts(x)   # 本机运维台
  agent/
    application/        # 会话状态、恢复与运行命令编排
    transport/          # 受约束的本机控制客户端
    cli/                # 参数、一次性输出与进程入口
    ui/                 # Ink 界面、增量时间线、滚动和编辑器
packages/conversation-presentation/src/
                        # 桌面对话与 CLI 共用的消息分类和工具配对
apps/server/src/operations/
                        # 本机 Broker 与服务主体边界
```

主服务的智能体运行仍位于 `apps/server/src/agent/` 与 `apps/server/src/agent-runtime/`。本机 CLI 不导入 `@openai/agents`，不创建应用容器，也不争抢数据库单实例锁。桌面对话与 CLI 共用业务展示投影，但保留桌面界面和终端各自的最终 Markdown 渲染器。
